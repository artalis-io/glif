# Privacy Policy — Glif: ASCII Video

**Last updated:** 2026-02-18

## Overview

Glif: ASCII Video is a browser extension that renders real-time ASCII art overlays on HTML5 video elements. All processing happens locally in your browser. No data is collected, transmitted, or shared with any third party.

## Data Collection and Storage

This extension does **not** collect, store, or transmit any user data whatsoever. No personal data, browsing history, video content, webcam footage, analytics, or any other information is recorded.

## Video and Webcam Access

When activated by the user, the extension reads video frames from HTML5 `<video>` elements and optionally intercepts webcam streams via `getUserMedia()`. All frame data is processed entirely on-device using a local WebAssembly module. No video or webcam data ever leaves your browser.

## Remote Code

The extension does not load or execute any remote code. All JavaScript and WebAssembly files are bundled within the extension package.

## Network Requests

The extension makes **zero** network requests. It does not communicate with any external server.

## Third-Party Services

The extension does not integrate with or send data to any third-party services, analytics platforms, or advertising networks.

## Changes to This Policy

If this policy is updated, the changes will be reflected in this document with an updated date.
